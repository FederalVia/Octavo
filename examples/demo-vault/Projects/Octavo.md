# Octavo

An Obsidian-like app that doubles as Claude's memory.

## Decisions
- Store notes as plain Markdown so they work with git and other editors.
- Expose the vault over [[MCP]] so Claude can read and write it.
- Visualise the vault as a brain, building on [[Graph Theory]].

## People
- [[Ada Lovelace]] is reviewing the design.
