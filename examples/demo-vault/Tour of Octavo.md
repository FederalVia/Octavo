# Tour of Octavo

1. **Atlas view.** Drag to rotate the brain and scroll to zoom. Each region holds a different kind of note (see [[Brain Regions]]).
2. **Network view.** Use the toolbar button to switch to a flat graph.
3. **Open a note.** Click any point. The note slides in on the right with its links and backlinks.
4. **Edit.** Press `Ctrl/Cmd+E` or click *Edit*. Type `[[` to link a note and `#` to add a tag.
5. **Find things.** `Ctrl/Cmd+O` opens the quick switcher and `Ctrl/Cmd+Shift+F` searches all notes.
6. **Journal.** `Ctrl/Cmd+D` opens today's daily note.
7. **Watch Claude think.** When Claude writes to a note, its point lights up. See [[How Claude uses this vault]].
